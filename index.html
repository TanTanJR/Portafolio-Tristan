04 · Trabajo

Proyectos destacados.

PROYECTO 01 · EN DESARROLLO

Camelia Books

Web de opiniones y recomendaciones de libros, pensada para organizar lecturas, descubrir nuevas historias y recoger recomendaciones de otros lectores.

HTMLCSSJavaScriptSupabaseAPI propiaVercel
Funcionalidades

Catálogo de libros, filtrado por categorías y envío de recomendaciones mediante un formulario conectado al servidor.

El reto y lo aprendido

Mi primer proyecto trabajando con una base de datos. Aprendí a conectar la interfaz con Supabase y una API propia, gestionar los datos enviados por los usuarios y resolver errores durante la comunicación entre los distintos servicios.

Diseño

Interfaz responsive adaptada a ordenadores y móviles, con una identidad visual inspirada en el mundo de la lectura.

PROYECTO 02 · EN DESARROLLO

Web Waterpolo Petrer

Web creada para presentar la identidad del club y reunir la información de sus equipos, partidos y actualidad en un mismo lugar.

HTMLCSSJavaScriptDatos con JavaScriptVercel
Funcionalidades

Presentación del club, consulta de equipos y partidos, y contenido organizado a partir de datos gestionados con JavaScript.

El reto y lo aprendido

Aprendí a estructurar una web con bastante información, separar los datos del contenido visual y mejorar distintas partes del proyecto sin perder coherencia.

Diseño

Diseño responsive, navegación clara y una imagen visual basada en la identidad deportiva del club.

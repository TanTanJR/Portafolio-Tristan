# Portfolio de Tristán Pérez Vecina

Portafolio personal creado para presentar mi perfil, formación, habilidades y proyectos de desarrollo web.

## Publicación en Vercel

1. Sube todos los archivos de esta carpeta a un repositorio de GitHub.
2. En Vercel, selecciona **Add New > Project**.
3. Importa el repositorio.
4. Deja **Framework Preset** en **Other**.
5. No escribas ningún comando de compilación ni carpeta de salida.
6. Pulsa **Deploy**.

El archivo principal es `index.html` y debe permanecer en la raíz del repositorio.

## Contenido

- `index.html`: página completa del portafolio.
- `Tristan_Perez_Vecina_CV.pdf`: currículum descargable enlazado desde la página.

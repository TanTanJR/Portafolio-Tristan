## Tecnologías

HTML · CSS · JavaScript · PHP · MySQL · Supabase · Git · GitHub · Vercel. También estoy aprendiendo C# y .NET; mi nivel en C# es básico.

## Ejecutar en local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/TanTanJR/Portafolio-Tristan.git
   ```
2. Abre `index.html` en el navegador o utiliza Live Server en Visual Studio Code.

El sitio es estático y no necesita un proceso de compilación.

## Estructura

- `index.html`: contenido y estructura de la página.
- `css/`: estilos.
- `js/`: interacciones.
- `Tristan_Perez_Vecina_CV.pdf`: currículum enlazado desde el portafolio.

## Publicación

El proyecto está publicado en Vercel desde este repositorio. Para desplegar una copia, importa el repositorio en Vercel con **Framework Preset: Other**, sin comando de compilación ni carpeta de salida.
